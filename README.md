# JavaScript ATM Projesi 🏦

Bugün JavaScript'te **Switch-Case** kullanarak bir ATM simülasyonu geliştirdik. 

* **Switch-Case Tercihi:** Çok seçenekli menü işlemlerinde kodun daha düzgün ve okunabilir olması için `if-else` yerine `switch-case` yapısını tercih ettik.
* **If-Else Kullanımı:** Para çekme sırasındaki bakiye kontrolü gibi belirli bir koşula bağlı (true/false) işlemlerde ise `if-else` yapısını entegre ettik.
